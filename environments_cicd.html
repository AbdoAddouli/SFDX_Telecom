Refresh: On demand
Source of truth: Git
Used for: Development, unit testing, rapid iteration
🟧 ats-int
Integration & SIT
Refresh: Nightly
Source of truth: Git + pricing export

Business acceptance
Refresh: Per release train

🟪 ats-prod
Production
Refresh: —

📦 CI/CD Pipeline (DevOps Center)

Pipeline: ats-dev → ats-int → ats-uat → ats-prod
Deploy order: CustomObject → CustomField → ValidationRule → CompactLayout → Flow → Apex → LWC → FlexiPage → PermissionSet → CustomTab
Gate: sf project deploy validate → tests → deploy
Pricing step: Controlled export from pricing-export/ — mandatory, not optional

📋 Deployment Order

CustomObject → CustomField → ValidationRule → CompactLayout →
Flow → Apex class → LWC → FlexiPage → PermissionSet → CustomTab

Deploying an LWC before its Apex dependency fails. DevOps Center handles ordering; without it, sequence must be managed manually.
